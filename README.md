# Гончарная мастерская

Сайт гончарной мастерской: услуги и онлайн-запись на занятия, мероприятия, магазин с корзиной и заказами, отзывы с модерацией, личный кабинет и админ-панель с ролями.
Учебная практика, вариант 2. Команда: Айзат (база данных, серверная логика, админ-панель) и Евгений (дизайн, вёрстка страниц).

**Стек:** C#, ASP.NET Core MVC (.NET 8), Entity Framework Core, SQLite, cookie-аутентификация, xUnit.

## Как запустить

Нужен .NET SDK 8 или новее.

```
dotnet run
```

Сайт откроется на http://localhost:5080. База `pottery.db` создаётся сама при первом запуске и заполняется тестовыми данными.
Чтобы начать с чистой базы, остановите сайт и удалите файл `pottery.db`.

Тесты:

```
dotnet test PotteryWorkshop.Tests
```

## Публикация

Сборка готовой версии для сервера:

```
dotnet publish -c Release -o publish
```

В папке `publish` появится всё нужное для запуска: `dotnet PotteryWorkshop.dll`.
Строка подключения к базе задаётся в `appsettings.json` (`ConnectionStrings:Default`).

Запуск в Docker:

```
docker build -t pottery-workshop .
docker run -p 8080:8080 pottery-workshop
```

## Что умеет сайт

| Раздел | Возможности |
|---|---|
| Главная | баннер, о мастерской, услуги, ближайшие мероприятия, рекомендуемые товары, отзывы, карта |
| Услуги и запись | услуги с ближайшими занятиями, расписание с фильтром, запись с проверкой мест, даты и повторной записи, отмена |
| Мероприятия | календарь, регистрация и отмена, учёт свободных мест |
| Магазин | каталог с фильтром по категориям и поиском, карточка товара, корзина, оформление заказа с проверкой остатков |
| Отзывы | список с фильтром по услуге, новый отзыв только после посещённого занятия или полученного заказа, модерация |
| Контакты | контакты, Яндекс.Карта, форма обратной связи (сообщения видны в админке) |
| Личный кабинет | профиль, мои записи, мероприятия, история заказов со статусами |
| Админ-панель | модератор: записи, расписание, мероприятия, просмотр отзывов и сообщений; администратор: дополнительно товары, заказы, модерация отзывов, пользователи и роли, статистика |

## Структура

| Папка | Что внутри |
|---|---|
| `Models` | классы таблиц базы данных и перечисления статусов |
| `Data` | `AppDbContext` (таблицы и связи) и `DbSeeder` (тестовые данные) |
| `Logic` | модули с бизнес-логикой: `BookingManager`, `OrderManager`, `EventManager`, `ReviewManager` |
| `Controllers` | контроллеры страниц и `AdminController` для админ-панели |
| `ViewModels` | данные форм с правилами проверки |
| `Views` | страницы Razor |
| `wwwroot/css` | стили по макету из Figma |
| `PotteryWorkshop.Tests` | unit-тесты на xUnit |
