# Гончарная мастерская

Сайт для гончарной мастерской, который мы сделали на учебной практике (вариант 2). На нём можно посмотреть услуги и записаться на занятие, зарегистрироваться на мастер-класс, купить готовые изделия, оставить отзыв. У мастерской есть админ-панель, где модератор и администратор ведут записи, расписание, товары и заказы.

Делали вдвоём: Айзат отвечал за базу данных, серверную логику, вход и админ-панель, Евгений за дизайн в Figma и вёрстку страниц.

Сайт работает онлайн: https://pottery-workshop-lanolikq.msk1.amvera.tech

Написан на C# и ASP.NET Core MVC (.NET 8). Данные хранятся в SQLite, работаем с ними через Entity Framework Core. Вход сделан на cookie, тесты на xUnit.

## Как запустить у себя

Нужен .NET SDK 8. В папке проекта:

```
dotnet run
```

Сайт откроется на http://localhost:5080. База `pottery.db` создастся сама и заполнится примерами. Если нужно начать с чистой базы, остановите сайт и удалите `pottery.db`.

На Windows можно просто запустить `run.bat`.

Тесты запускаются так:

```
dotnet test PotteryWorkshop.Tests
```

## Что есть на сайте

На главной собрано всё понемногу: о мастерской, услуги, ближайшие мастер-классы, товары, отзывы и карта. В разделе услуг у каждого направления видны ближайшие занятия, а на странице записи есть расписание с фильтром. Записаться нельзя на прошедшее занятие, на занятие без свободных мест и второй раз на одно и то же, запись можно отменить.

В магазине есть фильтр по категориям и поиск, корзина и оформление заказа. При заказе проверяется остаток на складе, а при отмене заказа товар возвращается обратно.

Отзыв можно оставить только после посещённого занятия или полученного заказа, и на сайте он появляется после проверки администратором. В личном кабинете видны свои записи, мероприятия и история заказов.

Модератор в админ-панели подтверждает записи, отмечает посещения, ведёт расписание и мероприятия. Администратору дополнительно доступны товары, заказы, модерация отзывов, сообщения с сайта, пользователи с ролями и сводка со статистикой.

## Как устроен проект

Контроллеры лежат в `Controllers`, страницы в `Views`, классы таблиц в `Models`. Правила записи, заказов, мероприятий и отзывов вынесены в отдельные классы в папке `Logic` (`BookingManager`, `OrderManager`, `EventManager`, `ReviewManager`), чтобы их можно было проверить тестами без запуска сайта. В `Data` находятся `AppDbContext` с таблицами и связями и `DbSeeder` с начальными данными. Формы с правилами проверки лежат в `ViewModels`, стили в `wwwroot/css`, тесты в `PotteryWorkshop.Tests`.

## Хостинг

Онлайн-версия размещена на Amvera в Docker-контейнере, настройки лежат в `Dockerfile` и `amvera.yml`. Локально контейнер можно собрать так:

```
docker build -t pottery-workshop .
docker run -p 8080:8080 pottery-workshop
```
